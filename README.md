# 🏢 RAVI Modular Cabinet – Booking System

A web-based **appointment booking and management system** built with **PHP and Firebase Realtime Database**.  
The project demonstrates a full-stack booking platform with a **customer-facing website and an admin dashboard for managing requests**.

> ⚠️ This project was built for **learning and portfolio purposes**.

---

# ✨ Features

### Customer Side
- Appointment booking form
- Contact form submission
- Responsive multi-page website
- Gallery with image preview
- Interactive animations and UI components

### Admin Dashboard
- Manage appointment requests
- View contact messages
- Search and filter records
- Update request status
- Delete individual or multiple records
- Print-friendly reports
- CSV data export
